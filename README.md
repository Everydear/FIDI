# FIDI KRW Dynamic V4

투자자 유형에 따라 ETF, 섹터 대표 개별주식 5종, 채권, 대체자산,
현금성 자산을 배분하는 원화 기준 포트폴리오 대시보드입니다.

## 주요 기능

- 안정형부터 대회형까지 5가지 투자자 유형
- 투자금액별 자산군·상품별 목표 금액 자동 계산
- 실제 거래소 티커와 공식 상품명 표시
- ETF, 개별주식, 채권, 대체자산, 현금성 자산 필터·검색
- 선택한 투자자 유형과 금액을 URL로 공유
- 한국시간 기준 화면 조회일 자동 갱신
- 모바일·태블릿·데스크톱 반응형 화면

## 데이터 상태

현재 V4는 규칙 기반 모델과 실상품 라인업을 보여주는 전략 설계
도구입니다. 실시간 시세, 자동 점수 계산, 증권사 주문은 아직 연결하지
않았습니다. 화면 조회일과 상품 라인업 검증일을 구분해 표시하며,
실제 주문 전에는 가격, 거래 가능 여부, 세금과 수수료를 다시 확인해야
합니다.

ETF 후보는 FUNETF와 각 운용사 공식 페이지, 국내 종목은 네이버 금융과
KRX, 섹터 대표주는 IndexErgo 및 각 기업의 공식 투자자 페이지를
참고합니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
corepack enable
pnpm install
pnpm dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 실행됩니다.

## 검증

```bash
pnpm test
```

프로덕션 빌드와 서버 렌더링 테스트를 함께 실행합니다.

## 배포

이 프로젝트는 vinext와 Cloudflare Workers 호환 빌드 구조를 사용합니다.
GitHub에는 소스와 검증 워크플로를 보관하고, 실제 공유 주소는
Cloudflare 기반 배포를 권장합니다.

## 주의사항

본 프로젝트는 투자전략 설계를 위한 모델 예시이며 투자 권유가
아닙니다. 모델 가정과 과거 데이터는 미래 수익을 보장하지 않습니다.
