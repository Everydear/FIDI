# FIDI KRW Dynamic V4.1

투자자 유형에 따라 ETF, 섹터 대표 개별주식 5종, 채권, 대체자산,
현금성 자산을 배분하는 원화 기준 포트폴리오 대시보드입니다.

## 주요 기능

- 안정형부터 대회형까지 5가지 투자자 유형
- 투자금액별 자산군·상품별 목표 금액 자동 계산
- 실제 거래소 티커와 공식 상품명 표시
- ETF, 개별주식, 채권, 대체자산, 현금성 자산 필터·검색
- 선택한 투자자 유형과 금액을 URL로 공유
- 한국시간 기준 화면 조회일 자동 갱신
- 매일 ETF·섹터 대표주 후보의 20일·60일 흐름과 변동성 점수 계산
- 교체 우위 기준을 넘을 때만 비교 가이드 제공
- 기준일·후보 비교·비용·실행 조건을 체크하는 일별 실행 전 체크리스트
- 일일 신호를 브라우저에 기록하고 JSON으로 내려받기
- 4단계 투자 성향 설문, 추천 유형 저장, 다른 유형 직접 비교
- 페이지 진입 시 선택 유형 편입상품의 최신 일봉 가격 조회
- 실제 수정주가·환율·거래비용 기반 서버 백테스트
- 전체 포트폴리오와 동일위험 정책 기준선 비교
- 정보비율, 전·후반 구간, 6개월 롤링, 비용 3배, 시작일·주기 민감도 검증
- 정책·데이터 한계·미래 관찰·체결 확인을 중립적인 운용 가이드로 표시
- Massive 미국 SIP 종가·배당 및 KRX 최근 공식 종가 교차검증
- 공급원 장애 시 미국 가격은 Yahoo Finance 조정 종가, 환율은 한국은행 ECOS로 자동 대체
- 상품별 가격 출처·대체 여부·최근 관측일·관측치 수를 결과 화면에서 확인
- ECOS 국내 CD(91일)·FRED 미국 3개월물 금리 API 연결
- 모바일·태블릿·데스크톱 반응형 화면

## 데이터 상태

현재 V4.1은 자산군 기준 비중을 유지하면서 ETF와 섹터 대표주 후보를
매일 같은 규칙으로 다시 평가합니다. 데이터가 짧은 항목은 한계로
표시하고, 미래 데이터 관찰과 체결 확인은 진행 가이드로 제공합니다.
주문 실행 기능과 증권사 계좌는 연결하지 않으며, 화면에는 각 시장에서
확인 가능한 최신 가격만 표시합니다. 미국 실시간 호가는 데이터 요금제
권한에 따라 제공 범위가 달라집니다.

ETF 후보는 FUNETF와 각 운용사 공식 페이지, 국내 종목은 네이버 금융과
KRX, 섹터 대표주는 IndexErgo 및 각 기업의 공식 투자자 페이지를
참고합니다.

## 백테스트 방법

- 기준 통화: KRW
- 가격: 배당과 분할을 반영한 일별 수정주가
- 미국 개별주: Massive SIP 종가와 Corporate Actions로 총수익률을 재구성
- 국내 자산: 수정주가 이력의 최근값을 KRX Open API 공식 종가와 대조
- 환율: FRED DEXKOUS 일별 USD/KRW 우선, 실패 시 한국은행 ECOS 036Y001/0000001로 대체(화면에 출처·최신값·기준일 표시)
- 휴장일: 각 시장의 직전 가격 유지
- 운용 구간: 모든 편입 상품의 가격이 존재하는 공통 구간
- 평가: 모든 유형의 후보 순위를 매일 계산
- 최신 가격: 미국은 Massive 최신 일봉, 국내는 Yahoo Finance 최신 일봉
- 실행 주기: 안정형·안정추구형·중위험형 분기, 성장형 월간, 대회형 주간
- 거래비용: V4.1 기준 일반형 20bp, 대회형 30bp를 회전금액에 적용
- 무위험금리: ECOS CD(91일) 기간평균 우선, 없으면 FRED DGS3MO 사용
- 공식 벤치마크: 현재 포트폴리오와 주식·채권·금·현금 위험예산이 같은
  정책 기준선. 주식 위험예산은 TIGER 미국S&P500(360750), 나머지는
  동일 상품·동일 비중으로 구성
- 시장 참고치: TIGER 미국S&P500(360750) 100% 보유. 채택 판정에는 사용 안 함

이 검증은 현재 화면의 고정 편입 종목을 과거에도 보유했다고 가정합니다.
과거 각 시점의 후보군에서 동일한 선정 규칙을 실행한 동적 종목선정
백테스트는 아니며, 이 차이를 결과 경고에 표시합니다.
미래 데이터 관찰은 2026-07-25 시작이며 일일 신호 기록을 축적해
2027-07-25에 1년 결과를 확인합니다.

미국 자산은 `MASSIVE_API_KEY`가 있으면 주 공급원으로 사용하고, 키가 없거나
호출에 실패하면 Yahoo Finance 조정 종가로 대체합니다. 환율은 `FRED_KEY`
또는 `ECOS_KEY` 중 하나가 필요합니다. 국내 최근 공식 종가 대조는
`KRX_AUTH_KEY`가 있으면 수행하며, 키가 없거나 승인이 안 된 경우에도
가격 이력과 대체 소스 상태를 표시하되 KRX 대조를 미완료로 기록합니다.
KRX에서 유가증권 일별매매정보와 ETF 일별매매정보를 각각 활용 신청·승인해야
합니다. Massive 무료 플랜은 최근 2년 범위이므로 요청 구간도 같은 범위로
제한합니다. 실시간 미국
호가·체결은 Massive 요금제 권한이 필요한 별도 범위이며, 현재 앱은
주문 없이 최신 일봉을 표시합니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
corepack enable
pnpm install
copy .env.example .env.local
pnpm dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 실행됩니다.
`.env.local`에 `ECOS_KEY`, `FRED_KEY`, `MASSIVE_API_KEY`,
`KRX_AUTH_KEY`를 설정합니다. 모든 키는 서버에서만 읽으며
`NEXT_PUBLIC_` 접두사를 사용하지 않습니다.
