# FIDI KRW Dynamic V4

투자자 유형에 따라 ETF, 섹터 대표 개별주식 5종, 채권, 대체자산,
현금성 자산을 배분하는 원화 기준 포트폴리오 대시보드입니다.

## 주요 기능

- 안정형부터 대회형까지 5가지 투자자 유형
- 투자금액별 자산군·상품별 목표 금액 자동 계산
- 실제 거래소 티커와 공식 상품명 표시
- ETF, 개별주식, 채권, 대체자산, 현금성 자산 필터·검색
- 선택한 투자자 유형과 금액을 URL로 공유
- 한국시간 기준 화면 조회일 자동 갱신
- 실제 수정주가·환율·거래비용 기반 서버 백테스트
- ECOS 국내 CD(91일)·FRED 미국 3개월물 금리 API 연결
- 모바일·태블릿·데스크톱 반응형 화면

## 데이터 상태

현재 V4는 규칙 기반 모델과 실상품 라인업을 보여주고, 현재 편입안을
과거 데이터로 검증하는 전략 설계 도구입니다. 실시간 주문과 증권사
계좌는 연결하지 않습니다. 화면 조회일과 상품 라인업 검증일을 구분해
표시하며, 실제 주문 전에는 가격, 거래 가능 여부, 세금과 수수료를
다시 확인해야 합니다.

ETF 후보는 FUNETF와 각 운용사 공식 페이지, 국내 종목은 네이버 금융과
KRX, 섹터 대표주는 IndexErgo 및 각 기업의 공식 투자자 페이지를
참고합니다.

## 백테스트 방법

- 기준 통화: KRW
- 가격: 배당과 분할을 반영한 일별 수정주가
- 미국 개별주: 일별 USD/KRW 환율로 원화 환산
- 휴장일: 각 시장의 직전 가격 유지
- 운용 구간: 모든 편입 상품의 가격이 존재하는 공통 구간
- 리밸런싱: 안정형·안정추구형·중위험형 분기, 성장형 월간, 대회형 주간
- 거래비용: 일반형 15bp, 대회형 25bp를 회전금액에 적용
- 무위험금리: ECOS CD(91일) 기간평균 우선, 없으면 FRED DGS3MO 사용

이 검증은 현재 화면의 고정 편입 종목을 과거에도 보유했다고 가정합니다.
과거 각 시점의 후보군에서 동일한 선정 규칙을 실행한 동적 종목선정
백테스트는 아니며, 이 차이를 결과 경고에 표시합니다.

가격은 `EODHD_API_TOKEN`이 있으면 EODHD를 사용하고, 없으면 Yahoo
Finance 공개 차트 응답을 검증용 대체 경로로 사용합니다. 공개 경로는
운영·감사 목적의 계약형 데이터 피드가 아닙니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
corepack enable
pnpm install
copy .env.example .env.local
pnpm dev
```

개발 서버는 기본적으로 `http://localhost:3000`에서 실행됩니다.
`.env.local`에 `ECOS_KEY`, `FRED_KEY`, 선택적으로
`EODHD_API_TOKEN`을 설정합니다. 모든 키는 서버에서만 읽으며
`NEXT_PUBLIC_` 접두사를 사용하지 않습니다.

## 검증

이 프로젝트는 vinext와 Cloudflare Workers 호환 빌드 구조를 사용합니다.
GitHub에는 소스와 검증 워크플로를 보관하고, 실제 공유 주소는
Cloudflare 기반 배포를 권장합니다.

## 주의사항

본 프로젝트는 투자전략 설계를 위한 모델 예시이며 투자 권유가
아닙니다. 모델 가정과 과거 데이터는 미래 수익을 보장하지 않습니다.
